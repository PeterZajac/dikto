# Changelog

## 0.1.4 — 2026-09-04

- New app icon (white ribbon on a black squircle) and a monochrome
  template glyph for the macOS menu bar.
- Playwright UI tests and an end-to-end pipeline test on Tauri's
  MockRuntime; no behaviour change.

## 0.1.3 — 2026-09-03

- Settings: the Claude model is picked from a list loaded from Meridian
  (`GET /v1/models`); falls back to a text field while Meridian is offline.
- Settings: a "Saved" confirmation flashes after every successful save.

## 0.1.2 — 2026-09-03

- macOS: the app bundle is now ad-hoc code-signed, so the Accessibility
  grant is recognised and the hotkey works. Previous builds showed the
  toggle as ON while the permission was dead.
- Release notes are generated by GitHub instead of copying the commit
  message.

## 0.1.1 — 2026-09-03

- English UI by default; Slovak switchable in Settings → Interface language.
  Applies to both windows, the tray and backend messages.
- Bubble retry button is driven by a `retryable` flag instead of matching
  message text.

## 0.1.0 — 2026-09-03

First public release.

- Crate and binary renamed to `dikto`.
- Windows: default hotkey is right Ctrl (right Alt is AltGr on SK/CZ
  layouts); privacy settings deep link; wizard hides the Accessibility row.
- History retention deletes completed dictations (text and audio) after the
  configured window; failed takes are kept.
- Step-by-step README, refreshed `docs/WINDOWS.md`.
